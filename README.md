# sofi website

Institutional and product demonstration website for sofi.

## Stack
- Next.js App Router
- React + TypeScript
- Tailwind CSS v4
- Motion for subtle interactions
- Lucide React icons

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Current scope
The homepage follows the supplied one-page reference: hero, extraction workspace, workflow, source traceability, developer/API example, football use cases and compact FAQ/footer. The workspace currently uses clearly identified illustrative sample data; it is not connected to the extraction API yet.
